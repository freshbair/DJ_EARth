What the image model learned

    One-dimensional k-means learns up to seven brightness groups from a sample of this image. Groups run from dark to bright across Do–Si. A uniform image has one group: Do. These groups affect pitch only in “Learn from image” mode.

    Fixed scale: floor(brightness × 7 / 256) → Do, Ré, Mi, Fa, Sol, La, Si (C4–B4). Brightness = round(0.2126R + 0.7152G + 0.0722B).

    Image brightness is a musical input, not a calibrated measurement of emitted light. Your upload stays in this browser. The piano is synthesized locally.
